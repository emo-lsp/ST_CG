# 江湖行卷状态栏贴图

《神雕同人》状态栏当前使用的 33 张 WebP，共 2,264,758 字节。仅发布运行时资源，不包含生成原图或未使用旧版。

| 目录 | 内容 |
| --- | --- |
| backgrounds | PC/手机横幅、宣纸与深色底纹 |
| landscapes | 眼前、人心、武路、旧事水墨与底栏远山 |
| frames | 外框、卷轴、角花、内栏与分隔线 |
| ornaments | 玉佩、流苏、桃花、卷册、剑谱与襄阳布幡 |
| controls | 按钮、导航玉牌与选中装饰 |
| labels | 题签、人物名帖与朱印 |

`manifest.json` 记录资源键、相对路径、字节数与 SHA-256。

前端使用固定 Git 提交版本，主源为 `testingcf.jsdelivr.net`，备用源为 `cdn.jsdelivr.net`。源文件仍保留在开发仓库 `src/神雕同人/界面/状态栏/assets/`；此目录与开场和武学详情素材相互独立。
